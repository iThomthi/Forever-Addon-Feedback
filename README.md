## Privacy and support

- **Public issues:** anything you write here can be seen by everyone.
- **Private code:** source repositories are separate and private.
- Do not paste passwords, API tokens, personal data, account details or private messages.
- For Lua bugs, include the addon version, game client version, steps to reproduce and an anonymized stack trace.
- Reports are submitted manually. WoW addons cannot upload reports to GitHub directly.
- This is a community feedback tracker, not an official World of Warcraft or CurseForge support channel.
